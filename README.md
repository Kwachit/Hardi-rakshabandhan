# For Hardi — A Rakhi From Miles Away ❤️

A mobile-first Raksha Bandhan website made as a digital gift.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save and wait for GitHub to publish the site.

## Personalize it

- Put your 30 photos in `assets/photos/` named `photo1.jpg` through `photo30.jpg`.
- Edit the letter inside the `.handwriting` section.
- Change the sibling jokes/statistics to your own inside jokes.
- Add music or other assets only if you have permission to use them.

Everything is plain HTML/CSS/JS, so there is no build step.

### Photo slots
The site includes 30 slots. Replace the empty files in `assets/photos/` with your own images, keeping the names `photo1.jpg` ... `photo30.jpg` (or update the extensions in `index.html`).
